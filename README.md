# 超市大亨・價格實驗室

六年級數學「折扣與賺賠」六詞定義互動教材。由《超市大亨爭霸戰・折扣與賺蝕》遊戲延伸，沿用同一套用語、色板與角色插圖。

- **線上教材**：<https://souchonun-arch.github.io/profit-loss-lesson/>
- **報告範例**：<https://souchonun-arch.github.io/profit-loss-lesson/report-preview.html>
- **原始碼**：<https://github.com/souchonun-arch/profit-loss-lesson>

## 教學目標

學生能說出六個詞的定義，並以成本為分母正確計算賺率與賠率。

| 詞 | 定義 | 公式 |
| --- | --- | --- |
| 原價 | 未減價前的標價 | — |
| 現價 | 折扣後實際收取的售價 | 原價 × 折扣 |
| 利潤 | 現價高於成本時賺到的金額 | 現價 − 成本 |
| 賠本 | 現價低於成本時賠去的金額 | 成本 − 現價 |
| 賺率 | 利潤佔成本的百分率 | 利潤 ÷ 成本 × 100% |
| 賠率 | 賠本佔成本的百分率 | 賠本 ÷ 成本 × 100% |

「成本」（入貨價）列為第 0 塊墊腳石，不計入六個進度徽章；沒有成本即無法計算利潤、賠本與兩個率。

> **用語備註**：本教材把「原價」定義為「折扣前的標價」，與延伸來源遊戲一致；部分課本把「原價」當作成本。請依 貴校教材版本核對後使用。全檔學生可見文字統一使用「折扣」「賠本」「不賺不賠」；僅單元名稱與遊戲名稱保留原有的「賺蝕」字樣。

## 七個學習站

| 站 | 內容 | 建議時間 |
| --- | --- | --- |
| ① | 一宗生意：情境投票與價格數線 | 3 分鐘 |
| ② | 六張定義卡，每張附「小判一判」 | 5 分鐘 |
| ③ | 價格實驗室：三條滑桿即時運算、分母對照開關 | 6 分鐘 |
| ④ | 六詞連連看 | 3 分鐘 |
| ⑤ | 三層挑戰六題（★☆☆／★★☆／★★★） | 6 分鐘 |
| ⑥ | 錯題修正：先診斷錯因，再重新作答 | 視錯題數 |
| ⑦ | 我的學習報告：產生單張 PNG，可下載上交、可列印 | 2 分鐘 |

第 ⑤ 站答錯的題目自動收錄至第 ⑥ 站，並記錄上次選了哪一個錯誤答案。兩步皆完成才標記「已訂正」；即使在原題按「再試一次」答對，仍須完成訂正。

報告圖在本機以 Canvas 繪製，內容包括掌握度與等第、六詞掌握燈號、三層答題長條、錯題數與訂正狀態、下一步建議、教師評語簽名欄。計分為定義卡 20%＋連連看 20%＋挑戰 40%＋錯題訂正 20%；全對無錯題時訂正項直接計滿分，並另列「第一次作答就答對 X / 6」。

## 資料與私隱

- 教材為**單檔離線 HTML**，所有角色圖片均以 base64 內嵌，沒有外部函式庫、字型或網路請求。
- 學生姓名、班別、座號與作答進度只儲存在該裝置的 `localStorage`；報告 PNG 由瀏覽器本機產生並下載。
- **沒有任何資料上傳至伺服器**。GitHub Pages 只负责派送靜態 HTML 檔案，不使用資料庫、雲端儲存或後端服務。
- 清除學習紀錄：按教材右上角的「↻ 重來」。

## 使用方式

1. 直接把線上教材連結發給學生，以手機、平板或電腦瀏覽器開啟即可。
2. 若校內網路不穩定，可下載 `index.html` 單一檔案，以離線方式開啟，功能完全相同。
3. 學生完成後，在教材第 ⑦ 站下載報告 PNG，再依 貴班既定方式上傳給教師。
4. 教師可列印教材第 ④ 站的定義筆記表，或列印報告圖作紙本存檔。

## 驗證紀錄

以 Playwright 實機開啟頁面，通過 78 項檢查：六詞定義與公式、價格實驗室三種情境（賺／賠本／不賺不賠）、滑桿即時運算、分母對照、六題正解必在選項、四級階梯提示、錯題兩步訂正、報告 PNG 真實產生並下載（檔頭為有效 PNG）、進度還原、列印範圍、390 px 手機零溢出、零 JavaScript 錯誤。

未覆蓋：Safari 與實體 iPad 實機測試、課標條文逐條對照（未提供課本版本，故未編造）。
